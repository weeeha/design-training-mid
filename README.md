# Тренировка продуктового дизайнера: 5 задач уровня мидл

**Коротко.** Пять задач, по которым можно тренироваться на уровень мидл и крепкий мидл. Каждая основана на реальном проекте: есть компания, пользователи, экраны «как сейчас», данные и критерии приёмки. Делаешь задачу в отведённое время, проверяешь себя по критериям, потом открываешь подсказки и дорабатываешь.

Компании, люди, цифры и правила во всех задачах вымышлены. Совпадения с реальными продуктами случайны.

| 1 | [Бумажная декларация → визард](tasks/01-tax-wizard/README.md) | мидл | 1–1,5 дня | условная логика форм, ошибки, расчёты |
| 2 | [Каталог с вариациями для B2B-магазина](tasks/02-lumber-variants/README.md) | мидл | 1–2 дня | модель данных, две стороны продукта, импорт |

Если делаешь по порядку, сложность растёт от первой задачи к пятой.

## Как тренироваться

1. Прочитай бриф задачи целиком и рассмотри экраны «как сейчас».
2. Засеки время. Таймбокс указан в брифе. Если не уложился, это тоже результат: запиши, на что ушло время.
3. Делай в Figma. Сдаёшь не только экраны, но и то, что указано в разделе «Что сдать»: схемы, матрицы, объяснения.
4. Проверь себя по разделу «Как поймёшь, что готово». Честно отметь, что не выполнено.
5. Только после этого открой `HINTS.md` в папке задачи и доработай.
6. Отправь ссылку на Figma на разбор. Разбор идёт по чек-листу [REVIEW.md](REVIEW.md).

## Что в папке задачи

```
tasks/<задача>/
  README.md    бриф: компания, пользователи, как сейчас, задача, критерии
  HINTS.md     где обычно ошибаются, вопросы к себе, иногда ответы
  screens/     экраны «как сейчас», которые нужно переделать
  data/        данные: прайс, ответы опроса и так далее (не во всех задачах)
```

Экраны «как сейчас» специально плохие. Это то, что пришло от прошлой команды, и именно их нужно переделать. Не копируй их стиль: визуальный язык выбирай сам или бери любую открытую дизайн-систему.

## Для того, кто правит задачи

Экраны собраны из HTML в `src/screens/` и рендерятся в PNG скриптом:

```bash
./src/render.sh
```

Нужен установленный Google Chrome. Имя файла `<папка-задачи>__<экран>.html` определяет, куда ляжет картинка. Высота кадра задаётся тегом `<meta name="shot-height" content="1100">`.
